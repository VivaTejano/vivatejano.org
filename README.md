# Viva Tejano Cultural Arts Foundation Website v0.1

Static HTML/CSS/JS website built for GitHub Pages.

Upload all files and folders to the root of the GitHub repository.

Main files:
- index.html
- about.html
- documentation-day.html
- vision.html
- leadership.html
- contact.html
- css/styles.css
- js/script.js
- assets/images/
- assets/logos/

To update the Documentation Day registration button later, search for `Registration Coming Soon` and replace the `href="#"` with your Google Form URL.
